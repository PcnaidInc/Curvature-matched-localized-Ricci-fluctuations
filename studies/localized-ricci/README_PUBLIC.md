# localized-ricci: prepared public distribution

This folder is derived from `BlackHoles_Localized_Inward_Recovery.zip` (SHA-256 `6dfce42994b5b82c15992430fc8c52336efdc907204f5d6d59579940d453b378`).
Scientific array files and retained numerical source programs are unchanged. Internal author guides,
publication-account notes, upload records, intermediate duplicate ZIPs, and presentation-only helpers
are not included. Internal tracker labels in explanatory documents are replaced with neutral labels.
This is a distribution/metadata revision, **not a new simulation**. See the root publication inventory.

Run `python reproduce.py verify` for file/block integrity only. Other modes are documented in
`reproduce.py` and are distinct from a fresh full calculation. Do not confuse a reference test or
cached-result assembly with numerical field production. Use a copy when running commands that write
results. The public top-level manifest reflects this curated folder, not the original whole ZIP.

No journal acceptance, independent peer review, experimental confirmation, or general quantum-dominance
claim is made. The optical-reference study is a benchmark, not a new SPV-1 interior noise result.
