# Rights and reuse

Public visibility is not a substitute for choosing an explicit reuse licence. No new blanket MIT,
CC BY, CC0, or other licence has been applied in this preparation step. Existing third-party licences
and scientific attributions, where present, remain in force. Original numerical results are not
relabelled as a third party's work, and original code is not itself evidence of scientific novelty.

Before an archival public release, the author should select appropriate licences separately for
manuscript text, numerical data, and code. The previously discussed non-exclusive arXiv distribution
licence is not a general licence for this code repository. No commercial publishing licence has been
executed through this package.
